# Object-avoidance-robot
In this repository, I discuss a project i was apart of last semester where my team built a robot from a MakeBlock kit. This includes the description, simulations and code.
Last semester apart of our module Robotics and control PBL. Me and my teammates built a MakeBlock robot and implemented an Object avoidance and line-following algorithm. We only had two requirements: 1. Use the MakeBlock kit with the MegaPi. 2. Implement a feedback control loop to it. So we had a lot of room for our imagination. 

After building the robot we added the components that we planned on using. First were the motor drivers, these simply had one job when the microcontroller told them to move it moved. Next we used an ultrasonic sensors, the sensors works by sending out waves of infrared lights. If the infrared light doesnt shine back into the sensor it knows that there is no objects ahead, else it can get the distance the object by checking how long it took the light to shine back. This allowed us to have our robot stop when it sensed an object is too close. Our last component was the line sensor, This component works by measuring the contrast of the ground.
